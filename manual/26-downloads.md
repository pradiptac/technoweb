# Downloads: datasheets, drivers and firmware

*Who can use this: Content manager and Administrator.*

**Content → Downloads** is where you keep the files that go with the hardware
you supply: datasheets, drivers, firmware, guides. Every published file is
listed on your website's **Downloads** page (`/downloads`), under its
category, and on the page of each product you attach it to.

A file can be open to everybody, or kept for **customers** — people signed in
to your customer portal.

## Adding a download

Press **New download**. The form has three tabs.

1. **Details** — the **Title** (what the file is), a one-sentence
   **Summary**, an optional **Version** and **Released on** date, its
   **Category**, and its **Order** within that category.
2. **File** — where the file is kept, who may download it, and the
   **Status**.
3. **Products** — tick the catalogue products and the shop products the file
   belongs to. It then appears under **Downloads** on each of those pages.

### Where the file is kept

- **From the media library** — choose a PDF, a document or an archive that is
  already in the library, or upload one in the dialog. This is the simple
  choice for a datasheet or a brochure.
- **Uploaded here (private)** — upload the file to the download itself. It is
  kept off the public part of the server and handed out by the website. Use
  this for **firmware, installers and drivers**, and for any file that only
  customers should get.

The form tells you the largest file your server accepts. A large upload shows
its progress as it goes.

### Who may download it

- **Everyone** — anybody who opens the page.
- **Customers only** — the file is still *listed* for everybody, with a lock,
  so people can see it exists. Pressing **Download** asks them to sign in to
  the portal first. Signed-in customers also find these files under
  **Downloads** in the portal.

> **Customers only needs "Uploaded here".** A file in the media library has a
> public address, so it cannot be restricted. Choose **Uploaded here** and
> upload the file.

### Publishing

Set the **Status** to **Published** and save. A download can be saved as a
draft before its file is ready, but it can be published only once it has a
file.

The **Downloads** link appears in your website's menus by itself once the
first download is published, and disappears again if there are none.

## Categories

Press **Categories** at the top of the Downloads screen. A category is a
heading on the Downloads page — *Datasheets*, *Drivers*, *Firmware*.

- **Order** sets the order of the headings.
- **Shown on the site** switches a whole category off, with everything in it,
  without deleting anything.
- Deleting a category keeps its downloads; they are listed without a
  category.

A category with nothing published in it is not shown.

## Replacing a file with a newer version

Open the download, go to the **File** tab and upload the new file (or choose
another from the library). Update the **Version** and **Released on** on the
**Details** tab. The old uploaded file is removed when the new one is saved.

## How often a file is downloaded

The Downloads screen shows a count for each file, and you can sort by it. The
count goes up each time somebody actually receives the file.

## Putting downloads on other pages

In the page builder, add a **Downloads** section and set **Which files** to
**From the downloads centre**. Choose a category, or leave it on every
category, and how many to show. The section always shows what is published
now.

## Deleting a download

Open it and press **Delete download**. It comes off the Downloads page and
off every product page. A file you uploaded to it is deleted with it; a file
from the media library stays in the library.

## If you had a page called Downloads

Earlier versions set up an ordinary page at `/downloads`. That address is now
the Downloads page described here. Your old page was kept as a **draft**
called *Downloads* under **Content → Pages** (its address is now
`/downloads-page`), so you can copy anything you wrote into a download's
summary or another page. Menu links to it now point at the new page.
